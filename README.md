# Chat Bot Agency

Premium responsive AI chatbot agency website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — complete page structure
- `style.css` — responsive glassmorphism design and animations
- `script.js` — theme toggle, mobile menu, reveal animations, chatbot demo, calendar and booking confirmation

## Run
Open `index.html` directly in a modern browser, or serve the folder with any static web server.

## Important
The booking system is currently a front-end demo. It does not send real emails or create calendar events. Connect the form to your preferred backend, calendar API, CRM, or booking provider for production use.

Replace placeholder company logos, contact/social links, pricing, testimonials and business details before launch.
